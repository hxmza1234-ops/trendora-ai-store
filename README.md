

## V3 changes
- Removed Spotify/Music UI and environment variables.
- Shopify is now a first-class integration status in the storefront.
- Keeps Shopify credentials server-only.
- Keeps Amazon discovery, protected admin refresh, webhook verification and 72-hour product refresh architecture.

## Important fulfillment note
This project does not auto-purchase Amazon retail orders. Amazon catalog/affiliate access and Shopify commerce are separate integrations; configure fulfillment only through providers and workflows permitted by their terms.
